# Security Policy

## Reporting Security Issues

The Spiderpool maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/spidernet-io/spiderpool/security/advisories/new) form.

For more details, see the [Spiderpool security policy](https://github.com/spidernet-io/spiderpool/blob/main/SECURITY.md).
